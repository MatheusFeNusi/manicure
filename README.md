# 💅 BellaNail Studio • Sistema para Manicure & Nail Designers

Um sistema web completo, moderno e com estética de salão de luxo para gestão de atendimentos de manicure, nail designers e estúdios de beleza.

## 🌟 Funcionalidades

- **📊 Dashboard & Visão Geral**:
  - Métricas de faturamento do mês, lucro líquido estimado e atendimentos do dia.
  - Lista da agenda do dia com status e horário de cabine.
  - Conclusão rápida de procedimentos com efeito comemorativo de confete.

- **📅 Agenda & Horários**:
  - Filtros ágeis (Hoje, Amanhã, Calendário por data).
  - Status em tempo real (*Agendado*, *Confirmado*, *Em Atendimento*, *Concluído*, *Cancelado*).
  - Botão de envio de lembrete formatado direto no WhatsApp da cliente.
  - Controle de pagamento (*Pago* / *Pendente*).

- **✨ Catálogo de Serviços & Nail Art**:
  - Categorias: Alongamento em Fibra de Vidro, Manutenção, Esmaltação em Gel, Mãos & Pés, SPA dos Pés e Nail Art Encapsulada.
  - Duração em minutos, valor em R$ e selos de destaque (*Mais Pedido*, *Tendência*, *Especial*).
  - Adição, edição e exclusão de procedimentos.

- **👥 Fichas de Clientes & Anamnese**:
  - Registro de formato de unha favorito (*Almond*, *Quadrada*, *Bailarina*, *Stiletto*, *Redonda*, *Oval*).
  - Ficha de anamnese e observações (alergias, cuidados com cutículas sensíveis).
  - Histórico de visitas, valor total investido e contato direto via WhatsApp.

- **💰 Controle Financeiro & Fluxo de Caixa**:
  - Lançamento de Entradas (atendimentos e produtos) e Saídas (insumos, géis, aluguel, etc.).
  - Cálculo de lucro líquido e margem estimada.

- **📱 Simulador de Agendamento Online da Cliente (Bio do Instagram)**:
  - Seleção múltipla de procedimentos com cálculo instantâneo de tempo e valor.
  - Escolha de data e horário disponível.
  - Envio da solicitação formatada para o WhatsApp do estúdio.

## 🚀 Como Executar Localmente

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/MatheusFeNusi/manicure.git
   cd manicure
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. Abra no seu navegador: `http://localhost:5173/`
